# Karigar Link v10 — Historical Data Management

## What changed
- Historical Data is now a complete import + management workflow.
- CSV and Excel (.xlsx/.xls) uploads are supported.
- Preview file before anything is saved.
- Automatic column detection with editable mapping for date, product, quantity, price, buyer, city and payment.
- Data quality report before import.
- Add to existing history or replace all existing history.
- Existing historical records are visible in a searchable, filterable paginated table.
- Import history shows file, rows, quality, mapping and actions.
- Export all or filtered historical records as CSV.
- Delete individual historical records.
- Delete an entire import/dataset.
- Delete all historical data.
- Original uploaded files are preserved separately and removed when their dataset is deleted.
- Historical summary cards show records, datasets, revenue, units, products and markets.
- Imported history continues to feed Overview, Market & Buyer Match and Impact Dashboard.

## Data ownership
Historical business records remain locally stored in the project database. Export and delete controls are available from the Historical Data section.

## Free-first
No paid AI API is required. Excel support uses openpyxl.
