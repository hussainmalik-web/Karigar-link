# Government Support vs Business Opportunities

Karigar Link keeps these two areas separate by design.

## Government Schemes

Answers: **What government support can I get?**

The page contains long/medium-term support programmes such as NHDP, CHCDS, PM Vishwakarma and National SC-ST Hub. Each record stores support type, target group, tags, summary, support coverage, eligibility, documents, application route, deadline/notice guidance, official URL and verification date.

## Business Opportunities

Answers: **What can I act on now?**

The page contains time-bound or actionable market-access routes such as Gandhi Shilp Bazar, Dilli Haat opportunities, institutional procurement routes and digital marketplace discovery. Event records include location, dates, application deadline, stall count when published, eligibility guidance and an official source link.

The Government of India Indian Handicrafts event calendar is treated as the authoritative source for event dates and deadlines. The application always sends the user to the official source to verify the latest status before acting.

Source: https://indian.handicrafts.gov.in/en/events
