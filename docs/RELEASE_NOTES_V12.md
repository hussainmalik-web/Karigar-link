# Karigar Link V2 Release Notes

## New sidebar modules

### Demand & Forecasting
Local forecast engine using historical sales, recent monthly averages and observed month seasonality. Produces 3-month expected units, expected revenue, capacity gap, peak forecast and confidence.

### Market Intelligence
Ranks product-market opportunities using explainable product attributes, buyer profiles, pricing, capacity and historical signals. Shows demand, competition, price fit, seasonality and reasons.

### Digital Marketplace
Adds a local artisan storefront, product cards, buyer request board and a form for publishing new buyer requirements. Existing buyer enquiries remain available for the next action.

## Free-first
No paid API is required. No claim is made of live external marketplace connectivity.
