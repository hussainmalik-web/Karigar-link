# Karigar Link v8 — Market Ready Workflow

## Goal
Extend v7 into a stronger free-first end-to-end prototype for the SIH26090 artisan market-linkage problem.

## Added
1. Market Ready Studio
2. Product photo upload and local preservation
3. Browser voice input using SpeechRecognition where supported
4. Explainable local product intelligence engine
5. One-click catalogue generation from artisan input
6. Smart pricing outputs
7. Primary market, customer segment and channel recommendations
8. WhatsApp, Instagram and B2B buyer content
9. Print / Save as PDF catalogue action
10. Buyer enquiry creation and enquiry list
11. CORS/API routing for frontend on port 5500 and backend on port 8765

## Transparency
The v8 free engine does not claim computer-vision understanding of the image. The uploaded photo is preserved, while product intelligence is generated from the artisan's structured text/voice input using explainable local rules. This avoids paid APIs and avoids pretending that an external AI service was used.

## Preserved from v7
Historical CSV import, data-quality scoring, product intelligence, pricing intelligence, market/buyer matching, detailed Smart Catalogue and Impact Dashboard remain included.
